## 1. The App
I am going to clone the Apple Stocks iOS app. The app is very straightforward. It allows you to add financial securities and assets to a watchlist. Clicking on an entry in a watchlist gives the user a graph view to see how the price of that financial asset has changed over a period of time. The user can change the period of time shown by the graph using buttons with different time intervals. The user can interact with the graph by hovering over certain areas, to view the price at specific time instances. The view also gives the user various basic information such as the open/high/low for that day, the 52 week high, 52 week low, etc. Lastly, the app suggests news articles that are related to the asset being viewed. I am choosing this app because I use it quite frequently to view how my investments are performing. I like using Apple’s stocks app because it is convenient and concise. Unlike the apps associated with brokerage accounts, you don’t have to log in to use the app. It also provides a clean view of your entire portfolio without overwhelming you with a bunch of complicated financial jargon. I also chose to clone this app because there are several things that I think I could add to make it a better and more complete portfolio tracker.

## 2. The Fundamental Problem
The app solves the problem of monitoring financial assets that are of interest to the user. It acts as a central view for all of the different assets in one’s portfolio. The app also serves as a handy way to stay informed about current events related to the financial market. 

## 3. What I’ll Keep
I am going to keep the app’s overall structure the same. The user will still be able to add assets to a watchlist. They will also still be able to click on any of the assets to view the graph and relevant information. Both of these features are fundamental to tracking the performance of financial assets so it would be counterproductive to remove them. Also, I like the simplicity of the app’s layout. There is one view showing the list of all of the assets of interest and a second view when the user clicks on an asset. The minimal amount of views makes the app really easy to navigate and checks many assets in a short amount of time. 

## 4. What I’ll Change or Remove
The app doesn’t provide the user with any way of actually seeing the value of their asset positions. I plan to add a feature where the user can create a watchlist where they also enter the details of their positions (i.e. number of shares, cost basis, gain/loss, etc.). I also plan to allow the user to switch the graph from showing the price history to instead showing position value history. I am also going to give the user the option to add a couple other data points to the graph. I want the graph to be able to show simple indicators such as moving averages and the Relative Strength Index. The only thing I am planning to remove from the original app is the feature that recommends related news articles. Although it is a helpful feature, I think implementing the search and information retrieval algorithms that would be necessary is not worth the effort for this project.
