## Smart Stock App

I am building an app that is very similar to the Stocks iOS app. The app should have a straight forward view of a user-selected list of stocks/financial assets. Each asset in the list should show the market value and the change in the price. The app should pull data using the Finnhub API and the open-source SwiftYFinance library. When you click on a financial asset, a second view should be pulled up where the user can see a graph showing the price history. This view should also include simple statistics about the asset. Do not worry about implementing any of the features that involve suggesting news articles related to the asset. There are two images in the current directory titled "Example" and "Example2" that show what the app should look like.

Implementation note: instead of the SwiftYFinance package, the app calls Yahoo Finance's chart endpoint (the same data SwiftYFinance wraps) through a small built-in client, `SmartStock/SmartStock/Services/YahooFinanceClient.swift`. Finnhub provides symbol search and stock quotes. Yahoo provides index quotes and all price history, because Finnhub's free tier has neither.

The project is located @Desktop/ECS191/Homework/

I have connected xcode via MCP so you can edit the project and run the simulator

Develop the app in the following phases:

Phase 1: Build the home view page. This should show a list of financial assets that the user is able to add. By default the list should contain the Dow Jones, NASDAQ, and S&P 500. There should be a search symbol (i.e. magnifying glass) in the top right of the view that can be used to search for assets and add them to the list. Each assets should show the current price and the latest day change of the asset. The exit criteria is that the the user can see stocks with the required quantitative details and have the ability to search for other assets to add. See the screenshot titled "Example" to see what the view should look like.

Phase 2: Build the second view where a user can click on one of the assets in the list to pull a more detailed graph showing the price history. Also add a section for the numerical details. For now, just add the numbers for Open, High, and Low. Don't worry about adding the visuals showing the volume of trades. And again, don't worry about adding anything related to suggested news articles. Add a couple of buttons above the graph that give the user the option to change the time scale of the graph. Only add buttons for as far back as Finnhub API and SwiftYFinance allows. The exit criteria should be that the user can click on an asset to see the graph and a section for relevant numerical values. The user should be able to see different amounts of the price history by clicking on buttons to change the time scale. The user can close the view to go back to the list view.

Phase 3: This phase should add more detail to the graph view. Give the user the ability to add other indicators to the graph. The two indicators you should add is the RSI and a Simple Moving Average. Add a check button in the numerical section to enable these indicators. The indicators should use time lengths corresponding to which timescale the graph is showing. When the user changes the graph time scale, the indicators should be updated. Make the lines for RSI and Simple Moving Average different colors to make them easy to see. Also add more numbers to the numerical section. These should include: 52 week high, 52 week low, Average Volume, and Volume. If any of the numbers are unable to be shown or calculated, indicate this with a small line like Example2 shows. The exit criteria of this phase should be that the user can enable the indicators, and the new stats should be shown under the graph.

Phase 4: This phase is where a lot of the new features (ones not included in the Stocks iOS app) will be implemented. When the user clicks the edit button on the home page, there should be an option to switch to a view that shows the users positions for certain assets (e.g. shares, % gain/loss, cost basis, day change). The default for this view show contain no financial assets. There should be a plus button that allows the user to choose an asset and enter information related to when they bought the asset. The user should be able to enter the price at which they bought the asset, either the number of shares that they bought, or the dollar amount of shares that they bought. They should also be able to input the date that they bought the shares. There should be a graph similar to the other views, that shows how the value of the users position has changed over a time interval starting from the date that they bought them. The exit criteria for this phase is the user being able to switch to this new view and add an asset that they have a position for. They should be able to input their details and see a graph showing the historical value of their position.

Phase 5: In the positions view, add a pie chart that shows the breakdown of asset distribution by the category that an asset belongs to (e.g. international stock, U.S. stock, government bond, etc.). Use the both data sources to find what category the asset belongs to. The exit criteria for this phase is a graph below the assets list in the portfolio positions view that gives the user a cleary idea of how their assets are distributed.
